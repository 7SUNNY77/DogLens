## Команда

```bash
uv run python scripts/prepare_dataset.py --images-dir data/images/Images \
  --annotations-dir data/annotations/Annotation --splits-dir data/splits --output-dir data/prepared
```

Время работы — около 26 с (8 потоков, CPU). Seed, `val_fraction` и `bbox_context` берутся из
`configs/training.yaml`: 42 / 0.2 / 0.1.

## Структура MAT-файлов (проверено, не предположено)

- Переменные `file_list`, `annotation_list` — cell-массивы `(N,1)`; scipy отдаёт их как
  `array([array(['dir/file.jpg'])], dtype=object)`. `labels` — `uint8 (N,1)`, значения 1..120.
- train = 12 000 (ровно 100 на класс), test = 8 580 (от 48 до 152 на класс);
  `file_list` = train ∪ test (20 580), совпадает вместе с метками.
- Каждая официальная метка соответствует ровно одной папке и наоборот. Порядок меток совпал с
  алфавитным порядком папок, но правило индексации на этом не основано.

## Mapping

- `class_id = официальная метка − 1` (0..119).
- `breed_key` — часть имени исходной папки `<wnid>-<Breed>` после дефиса в нижнем регистре
  (`chihuahua`, `black-and-tan_coonhound`); уникальность проверяется.
- `name_en` — та же часть, `_` заменено пробелом, первая буква заглавная.
- `wnid`, `source_dir` и `source_label` хранятся рядом.
- Единый источник — `data/prepared/class_mapping.json` с полем `mapping_sha256 = d9779c77…3c5f`.
  `assets/breeds.json` генерируется из него с тем же хешем; тесты проверяют согласованность.
- `name_ru`: проверенных переводов нет. Все 120 записей — `null`, интерфейс показывает `name_en`.
  Переводы добавляются в `assets/breed_names_ru.json` только с указанием проверяемого источника.

## Соглашение координат XML

Статистика по всем 22 126 рамкам:

| Наблюдение | Количество |
|---|---|
| `xmin == 0` | 2 278 |
| `ymin == 0` | 1 540 |
| `xmax == W` | **0** |
| `xmax == W−1` | 1 867 |
| `ymax == H` | **0** |
| `ymax == H−1` | 4 632 |
| рамки `0..W−1` на всю ширину | 237 |
| `xmax > W` / `ymax > H` | 2 / 1 (в 2 файлах) |
| `<size>` в XML ≠ реальному размеру | 0 из 20 580 |
| EXIF orientation 2..8 | 0 (82 файла с 1, один с невалидным 0) |

Вывод:
- начало отсчёта (0,0) — левый верхний пиксель изображения в том виде, как оно хранится;
- `xmax`/`ymax` — **включающие** индексы пикселей. Значения 0 встречаются, поэтому отсчёт не с 1;
  рамки, касающиеся правого/нижнего края, всегда заканчиваются на W−1/H−1 и никогда на W/H.

Преобразование: `xml_box_to_internal` → `(xmin, ymin, xmax+1, ymax+1)`.

EXIF: рамки относятся к хранимым пикселям; обучающие изображения не транспонируются. Запись с
orientation 2..8 была бы исключена с причиной `exif_rotation_unsupported` — таких записей 0.

## Политика кадрирования

- Используется крупнейшая валидная рамка; при равной площади — первый `<object>` в XML
  (на реальных данных равенств нет).
- Контекст: +10% ширины слева и справа, +10% высоты сверху и снизу; floor для min, ceil для max,
  обрезка по границам изображения.
- В manifest хранится нормализованная исходная рамка без контекста. Контекст и кроп вычисляются на
  лету (`data_prep.context_box`) — это решение для будущего Dataset/training: кропы заранее не
  создаются.
- Лимиты загрузки (10 MiB, 20 MP, ROI ≥ 64 px) к датасету не применяются: у 81 записи меньшая
  сторона рамки < 64 px, все они сохранены.

### Шаг 4.0: исключение точных межсплитовых дубликатов (SHA-256) и конфликтов меток из train/val

Политика:
- из train/val убирается каждая запись, точная копия которой есть в официальном test;
- из train/val убирается каждая запись, содержимое которой размечено другой породой; если такая
  пара целиком внутри train/val, уходят обе копии;
- официальный test не изменяется, его записи только помечаются.

Исключение применяется после назначения validation, поэтому распределение остальных записей не
сдвинулось.

### Ограничение: пересечение с ImageNet

Stanford Dogs собран из изображений ImageNet, а backbone инициализирован весами
EfficientNet-B0, обученными на ImageNet-1k (`data/weights/SOURCE.json`). Эти веса могли видеть
часть test-фото, пусть и под ImageNet-метками. Поэтому метрики на официальном test **оптимистичны**
и не являются независимой внешней оценкой. Для внешней проверки нужны собственные фото с
подтверждённой породой, не из ImageNet.
