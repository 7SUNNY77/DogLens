# Визуальная проверка подготовки датасета

- Дата: 2026-10-13. Подборка: `data/prepared/visual_check/` (26 панелей + `index.json`; в Git не добавляется).
- Генерация воспроизводима: `uv run python scripts/prepare_dataset.py` (по умолчанию `--visual-sample 26`,
  выбор детерминирован: сначала пограничные случаи, затем случайные породы с seed=42).
- Легенда панели: слева — исходник с нормализованной рамкой (красная); в центре — рамка + 10% контекста
  (зелёная); справа — итоговый кроп с контекстом.
- Способ просмотра: все 26 панелей открыты и просмотрены как изображения по отдельности.

## Что проверялось

- Рамка охватывает собаку; нет систематического сдвига или зеркалирования.
- Ориентация: рамки совпадают с изображением как оно хранится (EXIF-поворотов в датасете нет).
- Контекст: +10% ширины слева/справа и +10% высоты сверху/снизу, обрезка по границам.
- Пограничные случаи: обрезанные рамки, рамка на всё изображение, касание краёв, несколько объектов,
  PNG-содержимое под расширением .jpg, EXIF-теги (orientation=1 и невалидное значение 0), очень
  маленькие рамки.
