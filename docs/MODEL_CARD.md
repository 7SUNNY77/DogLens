# DogLens — Model Card

## Назначение

Модель ранжирует 120 пород Stanford Dogs по внешнему сходству собаки в выбранной пользователем
области фото и возвращает top-3 с softmax-оценками. Оценки отражают выбор модели **среди
поддерживаемых пород**. Это не генетические доли, не гарантия правильного ответа и не
калиброванная вероятность. Модель не определяет «не собака», «метис» или породы вне 120 классов.

## Лицензия и условия

Веса доступны в релизе v0.1.0 на условиях [MODEL_TERMS.md](MODEL_TERMS.md): некоммерческое
исследовательское и учебное использование, атрибуция, без гарантий. Лицензия MIT относится только
к исходному коду.

## Предназначение и неподходящее использование

- **Для чего:** локальная демонстрация и личное любопытство — какие из 120 пород Stanford Dogs
  визуально ближе всего к собаке в выбранной области фото.
- **Не для чего:**
  - подтверждение породы или происхождения собаки;
  - родословные, разведение, страхование, ветеринарные или юридические решения;
  - определение метисов;
  - вывод «на фото нет собаки».

## Архитектура

- `torchvision.models.efficientnet_b0(weights=None)`, `classifier[1]` заменён на `Linear(1280, 120)`.
- Обёртка — `doglens.model.BreedClassifier`, префикс ключей `state_dict` — `net.`.
- Инициализация backbone: `EfficientNet_B0_Weights.IMAGENET1K_V1` из официального URL torchvision,
  SHA-256 `7f5810bc96def8f7552d5b7e68d53c4786f81167d28291b21c0d90e1fca14934`
  (см. `data/weights/SOURCE.json`). Эти веса нужны только для инициализации обучения. Финальная
  модель — `artifacts/model_bundle/weights.pt`.

## Данные

- Stanford Dogs, официальное разделение `lists.tar` (SHA-256 сверен с TFDS).
- Mapping: `class_id = официальная метка − 1`.
- Validation — 20% из официального train, stratified, seed 42; копии одного фото внутри train не
  разделяются между train и validation.
- Из train/val исключены обнаруженные **точные** межсплитовые дубликаты по SHA-256 и копии с
  конфликтом меток (67 записей). Официальный test не изменён, его записи помечены флагами.
  Near-duplicates не проверялись.
- Итог: train 9 551 / val 2 382 / test 8 580.
- Подробности: `reports/dataset_preparation.md`.

## Вход и preprocessing

- Кроп: крупнейшая рамка аннотации + 10% ширины/высоты с каждой стороны, обрезка по границам.
- Затем единый детерминированный pipeline (`assets/preprocessing.json`):
  resize меньшей стороны 256 (bicubic, antialias) → center crop 224 → float → нормализация ImageNet.
- Train-аугментация: только горизонтальное отражение, до preprocessing.
- **Политика кропа в приложении:**
  - рамка пользователя проверяется (≥ 64×64 px исходного фото после EXIF);
  - затем расширяется на 10% ширины/высоты с каждой стороны с обрезкой по границам — так же, как
    рамки аннотаций при обучении;
  - «Использовать всё изображение» — всё фото без расширения;
  - контекст добавляется один раз в `roi.model_region`; эту функцию используют и превью UI, и
    predictor.
  - `metadata.json` bundle не менялся: поле `crop_policy.app` в нём осталось из экспорта, а
    фактическая политика приложения описана здесь, в README и `Predictor.crop_policy()`.

## Обучение

- Запуск `effb0-seed42-exp1`, CPU, seed 42, float32, batch 16, AdamW (weight decay 1e-4).
- Этап A: голова, lr 1e-3, 3 эпохи. Этап B: `features.6–8`, lr 1e-4, BatchNorm `frozen`, 5 эпох.
  Early stopping patience 3.
- Суммарное время эпох ≈ 57 мин. Подробности, история и сбой/resume на переходе A→B —
  `reports/training_exp1.md`.
- **Выбрана модель этапа A, эпоха 3**: лучший validation Top-1 за весь эксперимент. Fine-tuning
  дал не больше 0.8497 val Top-1, val loss рос.
- Bundle: `artifacts/model_bundle`, model_version `doglens-effb0-effb0-seed42-exp1-de6c9770`,
  weights SHA-256 `de6c9770242e2047aedb0b48055772f7052a5376a4a9bb1ca654c3223d807393`.
- Коммита git при обучении не было (`commit: null`).

## Результаты

Модель выбрана по validation. Test оценён один раз после выбора.

| Split / срез | Правило | Изображений | Классов | Top-1 | Top-3 | Macro F1 (120 labels) | Macro F1 (присутствующие) |
|---|---|---|---|---|---|---|---|
| validation | весь val | 2 382 | 120 | 0.8745 | 0.9702 | 0.8737 | 0.8737 |
| **test, full** | весь официальный test | **8 580** | 120 | **0.8725** | **0.9802** | **0.8665** | 0.8665 |
| test, clean | `dup_with_test == 0 and label_conflict == 0` | 8 527 | 120 | 0.8732 | 0.9803 | 0.8670 | 0.8670 |
| test, multi_box | `n_boxes > 1` | 595 | 111 | 0.8202 | 0.9513 | 0.7128 | 0.7706 |
| test, single_box | `n_boxes == 1` | 7 985 | 120 | 0.8764 | 0.9823 | 0.8710 | 0.8710 |

- Macro F1 считается как `f1_score(average='macro', zero_division=0)`, labels = 0..119; столбец
  «присутствующие» — только классы с support > 0. В срезе `multi_box` есть только 111 классов,
  поэтому его macro-метрики **не сравнимы напрямую** с остальными.
- Срез `clean` убирает 53 записи: точные копии из train/val и конфликты меток. Он **не**
  становится независимым от ImageNet-предобучения.
- Чаще всего путаются (test, true → predicted):
  - siberian_husky → eskimo_dog — 41 (45% support);
  - shih-tzu → lhasa — 20;
  - silky_terrier → yorkshire_terrier — 20;
  - pembroke → cardigan — 20;
  - deerhound ↔ irish_wolfhound — 16 и 15;
  - staffordshire_bullterrier → american_staffordshire_terrier — 15.
- Худший recall на test:
  - siberian_husky 0.457;
  - border_collie 0.620;
  - eskimo_dog 0.620;
  - toy_poodle 0.647.
- Полные per-class recall/support, confusion matrix и top-5 по каждому `image_id`:
  `reports/evaluation/test/`.
- Внешняя проверка (свои фото с подтверждённой породой) — **не проводилась**.

## Inference

Скорость на CPU (Intel Core Ultra 7 155H, Windows 11, batch 1, после прогрева, медиана / p95,
`reports/benchmark/`):
- forward — ≈ 20 / 24–39 мс;
- `predict()` на фото 333×500 с рамкой — 24.9 / 31.0 мс;
- декодирование + `predict()` для синтетического 4032×3024 — 191 / 222 мс;
- холодно: импорт библиотек ≈ 7 с, загрузка bundle ≈ 0.2–0.3 с.

Equivalence check: на 22 изображениях test predictor с рамкой из аннотации воспроизводит top-3 и
score сохранённой оценки (`tests/test_predictor_real.py`).

## Ограничения

- **Пересечение с ImageNet.** Stanford Dogs собран из ImageNet, а backbone предобучен на
  ImageNet-1k. Метрики на test оптимистичны, включая срез `clean`: он убирает только точные
  дубликаты и конфликты меток. Это не независимая внешняя оценка.
- **Шум разметки.** Политика «крупнейшая рамка» в кадрах с несколькими собаками может захватывать
  других собак или выбрать собаку другой породы (`reports/dataset_visual_check.md`). В test есть
  30 записей с конфликтом меток.
- **Близкие породы.** Визуально близкие породы путаются (см. confusion pairs в отчёте оценки).
- **Вне 120 классов.** Метисы, породы вне списка и изображения без собак всё равно получают top-3
  среди 120 классов.
- **Калибровка не проверялась.**
- **Внешняя проверка** на собственных фото с подтверждённой породой не проводилась
  (статус `not_performed`, инструкция — `docs/EXTERNAL_VALIDATION.md`).
- В приложении пользователь сам выбирает рамку. Её плотность и масштаб могут отличаться от
  аннотаций Stanford Dogs, и влияние этого не измерено.
