# Внешняя проверка DogLens

**Статус: `not_performed`.** Фотографий вне Stanford Dogs с подтверждённой породой пока
нет, а изображения из интернета не скачивались.

Метрики **87.25% Top-1 и 98.02% Top-3 получены на официальном test Stanford Dogs**, а не на новых
пользовательских фото. Этот test происходит из ImageNet, как и данные предобучения, поэтому
метрики оптимистичны. На реальных фото точность может быть заметно ниже. Изображения Stanford
Dogs внешней проверкой не являются.

## Чеклист ручной приёмки

Нужен установленный bundle: `artifacts/model_bundle/` или путь через `DOGLENS_BUNDLE_DIR`, см.
README. Запуск: `uv run streamlit run app.py`.

- [ ] Фото одной собаки известной породы: сравнить «всё изображение» и выбранную область.
- [ ] Плотная рамка вплотную и свободная рамка с запасом: кроп в превью = рамка + 10%.
- [ ] Несколько собак: выбрать одну и затем другую, результат должен меняться.
- [ ] Новое фото после результата: старый результат и рамка сбрасываются.
- [ ] Ошибочный файл (HEIC/GIF/PDF/текст или > 10 МиБ): понятная ошибка на русском.
- [ ] Метис и фото без собаки. Это проверка **ограничений**, а не accuracy по 120 классам:
      модель всё равно вернёт три породы.
- [ ] Отправить отзыв; повторная отправка — «уже сохранён». «Очистить» убирает фото и результат.
- [ ] Широкое окно и узкое (телефон или узкое окно браузера).

Что уже проверено автоматически, это не заменяет ручную приёмку:
- 11 сценариев Streamlit `AppTest`;
- реальный headless Chrome через DevTools — 30 проверок на ширине 1366 и 390 px с фото из
  Stanford Dogs. Это проверка интерфейса, а не внешняя проверка модели.

## Как проверить свои фото

1. Сложите фото (JPEG/PNG/WebP) в локальную папку, например `my_photos/`. В Git её не добавляйте.
2. Необязательно: создайте `labels.csv` (UTF-8):

   ```csv
   file,expected,xmin,ymin,xmax,ymax
   rex.jpg,beagle,120,80,900,760
   park.jpg,mixed_breed,,,,
   cat.jpg,not_dog,,,,
   ```

   - `expected` — либо `breed_key` из каталога (`assets/breeds.json`, вкладка «Поддерживаемые
     породы»), либо `mixed_breed`, `not_dog`, `unsupported_breed`, `unknown`.
   - Рамка (необязательно) — рамка пользователя в пикселях фото после EXIF-поворота, до
     добавления контекста. Пустые поля — всё изображение.
3. Запустите:

   ```bash
   uv run python scripts/check_photos.py --input-dir my_photos --labels my_photos/labels.csv
   ```

4. Результаты появятся в `reports/external_check/` (вне Git, там имена ваших файлов):
   - `predictions.csv` — top-3 по каждому фото;
   - `summary.json` — сводка.
   Top-1/Top-3 считаются **только** для фото с поддерживаемой породой. Метисы, другие породы и
   фото без собак перечисляются отдельно: модель всегда отвечает одной из 120 пород, поэтому это
   анализ ограничений, а не accuracy.

Небольшую выборку нельзя сравнивать с метриками test напрямую. Указывайте число фото.

## Сценарии ручной проверки в UI

Запуск: `uv run streamlit run app.py`, затем откройте http://localhost:8501.

| # | Сценарий | Действие | Что ожидать / что записать |
|---|---|---|---|
| 1 | Одна собака крупно | всё изображение и рамка | top-3 разумны; сравнить результаты двух режимов |
| 2 | Собака далеко | всё изображение, затем рамка вокруг собаки | рамка должна заметно помочь; при маленькой рамке — предупреждение |
| 3 | Несколько собак | выбрать одну рамкой | результат меняется при выборе другой собаки |
| 4 | Плотная и свободная рамка | рамка вплотную, затем с запасом | контекст 10% добавляется один раз, кроп виден в превью |
| 5 | Всё изображение | переключатель «Использовать всё изображение» | кроп = всё фото, без расширения |
| 6 | Размытое фото | всё изображение / рамка | ожидаемо низкие или нестабильные оценки |
| 7 | Метис | рамка | модель всё равно выберет породы из 120; отметить «Собака — метис» |
| 8 | Фото без собаки | всё изображение | модель всё равно вернёт 3 породы — это ограничение; отметить «Породы нет среди поддерживаемых» |
| 9 | Повороты EXIF (фото с телефона) | загрузка | превью ориентировано правильно |
| 10 | Неподдерживаемые файлы (HEIC, GIF, PDF, >10 МиБ) | загрузка | понятное сообщение на русском |

Результаты ручной проверки фиксируйте в отдельном отчёте: дата, устройство, число фото,
наблюдения. Не включайте фото в репозиторий.
